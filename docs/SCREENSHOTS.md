# rn-ui-kit 2.0.0 截图 / Screenshots

[返回中文 README](../README.md) · [Back to English README](../README_EN.md)

以下为 **2.0.0** 示例应用的实拍截图，更新于 **2026-11-27**。每组按 Android、iOS 18、iOS 26 并排展示同一演示场景，涵盖新版 HeroUI 界面和保留的原生组件。

Actual screenshots of the **2.0.0** example app, captured on **November 27, 2026**. Each row compares the same demo on Android, iOS 18, and iOS 26, showing both the new HeroUI appearance and the retained native components.

| 平台 / Platform | 设备 / Device | 系统 / OS |
| --- | --- | --- |
| Android 真机 / Physical device | Xiaomi M2102J2SC | Android 15 |
| iOS 模拟器 / Simulator | iPhone 16 Pro | iOS 18.1 |
| iOS 模拟器 / Simulator | iPhone 17 Pro | iOS 26.4.1 |

全部使用浅色模式，保留各设备原有主题色，因此 Android 与 iOS 的主色有所不同。图片仅作等比缩小与 JPEG 压缩，未修改界面内容；文件按组件或场景命名。

All captures use light mode and preserve each device's theme preferences, so the Android and iOS accent colors differ. Images are proportionally resized and JPEG-compressed without altering the UI, and filenames describe the component or scene.
